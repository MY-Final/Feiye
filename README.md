# 扉页 · Feiye

> 每一篇，都从扉页开始。

扉页是一款**本地优先的 Markdown 桌面编辑器**。它不接管你的文件，不要求登录，也不把内容藏进数据库——每一篇文档都是磁盘上一个普通的 `.md` 文件。打开即写，保存即落盘。

---

## 为什么叫扉页

扉页是一本书的标题页，是正文开始之前的那一页。它不喧宾夺主，却决定了读者对一本书的第一印象。

我们希望这款编辑器也是这样：安静地待在系统里，不打断思路，只负责把文字稳稳地留在本地。

英文名 **Feiye** 直接取自拼音，短、好记，也方便作为仓库名、包名和命令名。

## 设计原则

1. **本地优先**
   文档保存在用户自己的磁盘上，离线可用，不需要账号，不依赖任何云服务。

2. **纯文本**
   Markdown 是唯一事实来源，不引入私有格式、数据库或隐藏元数据。用户随时可以用任何编辑器打开自己的文件。

3. **快**
   Tauri 2 使用系统 WebView，冷启动和内存占用都优于 Electron；编辑器采用 CodeMirror 6，面向大文档优化。

4. **安静**
   界面克制，默认只保留写作需要的东西。功能可以多，但不能挤占正文。

5. **数据安全**
   原子写入、自动保存、外部修改检测、崩溃恢复副本。任何可能覆盖用户内容的行为都必须明确提示。

6. **安全渲染**
   Markdown 中的 HTML 经过清理；Mermaid 使用严格模式；外部链接交给系统浏览器打开。

## 功能规划

### 已完成（当前里程碑）

- 工作区与文件树：打开一个文件夹作为工作区；只展示目录与 `.md` / `.markdown` / `.mdx`；懒加载、右键新建 Markdown 或文件夹、重命名、删除（进回收站）；记住上次工作区；图片资源目录 `assets/` 默认不占用文件树；树行带文件类型图标与缩进参考线，头部可新建文件/文件夹、刷新文件树、一键折叠
- 文件操作：打开、手动保存（Ctrl/Cmd+S）、保存冲突检测（拒绝静默覆盖，可重新加载）；停止输入后自动保存（默认约 1.8 秒，可在设置中调整），状态栏显示「待保存 / 保存中 / 已保存 / 保存暂停」
- 崩溃恢复：编辑期间按设定间隔把未保存内容写入应用数据目录的恢复副本（默认约 4 秒），正常保存或放弃修改后清理；意外退出后下次启动提示恢复，恢复内容先进入编辑器，不会立即覆盖源文件
- CodeMirror 6 编辑器：Markdown 语法高亮、行号（可关闭）、查找替换、撤销/重做、换行与光标状态
- 四种视图：源码 / 分栏 / 预览 / 所见即所得，切换带滑动高亮，选择会持久化；可在偏好设置中固定启动视图
- 分栏：拖动中间分隔条调整编辑与预览的宽度，方向键微调、双击恢复等分；比例会持久化
- 所见即所得（Live Preview）：标题、强调、删除线、行内代码、链接、引用、列表、任务复选框、围栏代码块、分隔线、KaTeX 公式与 GFM 表格；光标进入元素时显示该元素的 Markdown 源码
- 代码块：底部语言输入框，直接键入或按 `↓` 从建议中选择，回车应用；支持任意自定义语言并实时高亮；`Ctrl+Shift+L` 聚焦语言框，块尾空行回车或 `Ctrl+Enter` 退出，未闭合的围栏会自动补全；所见模式的语言栏和预览代码块都带「复制」按钮并短暂反馈
- 状态栏：文件路径、行:列、字数、编码与保存状态；保存状态变化时淡入更新
- Typora 式工具栏：新建、保存、重命名，加粗、斜体、删除线、行内代码、链接、标题、引用、三种列表、代码块、公式、表格、分隔线；按钮激活态跟随光标
- 分隔线：工具栏命令会保证上下留空行；在正文下一行直接输入 `---` 时，所见模式也会自动补空行，避免被解析成 Setext 标题下划线（代码块、引用和列表内保持原语义）
- 图片排版：在图片后追加 `{width=… align=…}` 控制宽度与对齐（宽度支持 `%` / `px`，对齐 `left` / `center` / `right`），图片的 `title` 显示为图注，例如 `![示意图](assets/a.png "图 1"){width=60% align=center}`。
- 本地图片：预览与所见即所得都能显示文档相对路径、工作区绝对路径与远程图片；支持从剪贴板粘贴或从资源管理器拖入图片，自动保存到文档同级的 `assets/` 并插入相对路径
- 标题大纲：侧栏「大纲」标签实时列出当前文档的 H1–H6，点击跳转，当前标题随光标高亮；代码围栏里的 `#` 不会误入大纲
- 分栏滚动同步：按标题锚点建立编辑区与预览区的纵向映射，任一侧滚动会带动另一侧；窄窗口上下堆叠时自动关闭同步
- 实时预览：GFM（表格、任务列表、删除线）、Shiki 代码高亮、KaTeX 行内与块级公式、Mermaid 图表（流程图、时序图等，严格模式；渲染失败保留源码并提示；主题切换时重画）
- 安全渲染：先 `rehype-sanitize` 再渲染，原始 HTML 中的脚本与事件属性会被清除
- 未保存守卫：切换文件、切换工作区、关闭窗口时提示保存 / 放弃 / 取消
- 写入可靠性：临时文件 + 原子替换；外部修改以 mtime 检测；目录监听（notify）实时刷新文件树，当前文档被外部修改或删除时主动提示
- 无边框窗口：自绘标题栏与最小化 / 最大化 / 关闭按钮，保留系统级拖拽、双击最大化与边缘缩放
- 界面：「墨线 · 靛青」——冷纸、墨字、靛青点缀、发丝分隔线与宋体标题
- 主题：跟随系统 / 浅色 / 深色三档，界面、编辑器语法色与 Shiki 代码块同步切换；点缀色可在「靛青 / 赭石 / 松绿」间选择，亮暗各有配色；主题与点缀色在首屏脚本中解析，启动不闪白
- 偏好设置：标题栏齿轮或 `Ctrl+,` 打开应用内弹层，左侧四类（外观排版 / 编辑行为 / 视图与预览 / 关于）；可调字号、行高、行宽、自动保存与恢复副本间隔、行号显示、默认视图；修改即时生效并写入 Tauri Store，重启后保留。
- 分屏对照：`Ctrl+\` 或命令面板打开右侧对照区，并排预览另一篇已打开的笔记，边写边查；对照区只读、链接不跳转，磁盘上的外部修改会自动刷新。
- 多标签：同时打开多篇笔记（上限 12 个标签），点击切换、`×` / `Ctrl+W` 关闭、`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环；未保存的标签带一个点。切走再切回时撤销历史与光标位置都还在；重启或切回这个库时，上次的一组标签按原顺序摆回来（已删除的笔记点开时报错并自动关掉标签）。标签多到放不下时在标签栏内横向滚动，切到哪个就自动滚到哪个，不会把窗口撑出横向滚动条。
- 文档历史：每次保存自动留档最近 20 份（内容与上一版相同则跳过），快照保存在应用数据目录、不写入工作区；`Ctrl+Alt+H` 或命令面板打开，可逐版预览并恢复到某个版本（恢复后作为未保存修改载入，确认保存才写盘）。
- 工作区全文搜索：侧栏「搜索」标签边输边搜全部 Markdown，按行匹配（大小写不敏感），结果显示路径、行号与命中行并高亮；点击或回车直接打开笔记并跳到该行。
- 自定义 CSS：偏好设置 →「外观排版」底部可直接写样式，实时作用于编辑器与预览，随偏好保存在本机；留空即关闭。
- 预览增量更新：同一篇笔记里输入时只替换变化的段落，未变的代码高亮、图表与图片留在原位，长文输入不再整篇重绘。
- 导出 PDF：`Ctrl+P` 或命令面板把当前笔记按打印版式（A4、白底、图片内联、代码与公式保留）放进系统打印对话框，选「另存为 PDF」即可导出。
- 命令面板：`Ctrl+Shift+P` 搜索并执行应用内动作（新建、保存、另存为、复制 / 导出 HTML、切换视图、专注模式、返回 / 前进、字号等），↑↓ 选择、回车执行、Esc 关闭。

| 代码高亮 | **Shiki** | 代码块高亮 | 与 VS Code 同源的语法和主题，输出稳定 |

### 依赖说明

- **Bun 不是 Rust 构建器**：它负责 `bun install`、前端脚本和统一的命令入口；Tauri 的 Rust 编译与安装包生成仍由 `tauri` CLI / Cargo 完成。
- **UI 层保持轻量**：不使用重型组件库；模态框、右键菜单、Toast 都是项目内的小组件，样式由 `src/styles/global.css` 的 CSS 变量统一控制。
- **Markdown 渲染不直接拼接 HTML**：统一走 `remark → rehype → sanitize` 管线，渲染结果可审计、可清理。

### 数据流

1. **打开文件**
   系统对话框或文件树 → Rust 读取文件 → 交给 CodeMirror 的 `EditorState`。

2. **编辑**
   CodeMirror 事务更新文档。分栏 / 预览模式下，文本经防抖交给 Web Worker 的预览管线；所见即所得模式直接由装饰扩展重绘当前视口，不再额外渲染预览。

3. **保存**
   停止输入约 1.8 秒，或按 Ctrl/Cmd+S / 点击保存 → 从 CodeMirror 取全文 → Rust 携带上次保存时的 mtime 原子写入 → 成功后更新状态栏并清理恢复副本。写入期间若继续输入，会再保存一次最新内容；内容仍有变化时保持未保存状态。

4. **崩溃恢复**
   编辑期间防抖写入应用数据目录的恢复副本；正常保存、重新加载或明确放弃修改后删除。启动时发现恢复副本会先与磁盘内容比较，相同则清理，不同则询问恢复 / 丢弃 / 稍后。

5. **外部修改**
   保存时若磁盘 mtime 与记录不一致 → 拒绝写入。手动保存会提示「文件已被其他程序修改」，可重新加载或取消；自动保存则暂停并在状态栏提示，按 Ctrl+S 处理。目录监听会在外部增删改后刷新文件树，当前文档被改或删除时主动提示。

### 关键设计

- **CodeMirror 是编辑状态的唯一来源。** React 不保留整篇文本的副本，避免大文档下的双份内存与状态不同步。
- **预览管线放在 Web Worker。** 解析、高亮等 CPU 工作不阻塞输入；过期的渲染任务直接取消。
- **Shiki 按需加载并缓存。** 以「语言 + 主题 + 代码哈希」为缓存键，避免重复高亮。
- **KaTeX 与 Mermaid 懒加载。** 只有文档中出现公式或图表时才加载对应模块。
- **Mermaid 严格模式。** 禁止图表中的任意脚本执行；渲染失败时保留源码并显示错误信息。
- **文件权限最小化。** Tauri capabilities 只授予工作区目录所需的读写权限，不开放任意路径。
- **Live Preview 与源码共用同一份文本。** 所见即所得不是另一套富文本模型：装饰只影响显示，光标所在的语法节点退回源码，撤销历史、保存与冲突检测完全复用。
- **块级装饰由 StateField 提供。** 表格与块级公式属于 CodeMirror 的块级装饰，必须来自 state field，才能稳定参与测量、滚动与光标映射。

## 性能策略

- 编辑输入不做同步的全量 Markdown 解析。
- 预览更新防抖 150–250ms，并丢弃过期的异步结果。
- 代码高亮与 Markdown 解析在 Web Worker 中执行。
- 大文档优先保证输入响应；预览可以降级为「延迟渲染」或「仅渲染可视区域」。
- 避免在 React 中逐字符更新；编辑器与预览之间只传递必要的文档版本号。
- 主题切换时复用已加载的 Shiki 主题，不重复初始化 highlighter。

## 安全与数据可靠性

### 安全

- Tauri capabilities 按工作区授权，默认不授予全局文件访问。
- 渲染进程启用 CSP，不加载远程脚本。
- Markdown 原始 HTML 经过 `rehype-sanitize` 或等价清理；禁止 `script`、`iframe`、`object`、`embed`、`form` 等标签。
- Mermaid 使用 `securityLevel: 'strict'`。
- 外部链接通过系统浏览器打开，不把任意 URL 直接交给 WebView。
- 远程图片默认允许 `https`，可在设置中关闭，避免不必要的网络请求与追踪。
- 本地图片通过自定义 `feiyeimg` 协议读取：只接受规范化后仍位于当前工作区内的绝对路径，扩展名限定为 png / jpg / jpeg / gif / webp / avif / bmp / ico（暂不含可执行脚本的 SVG），单文件上限 16 MiB，并返回 `X-Content-Type-Options: nosniff`。

### 数据可靠性

- 保存采用「临时文件 + 原子替换」，降低写入中断导致的文件损坏。
- 默认启用自动保存：停止输入约 1.8 秒后写入源文件；手动保存仍然可用。切换文档、切换工作区、关闭窗口前会先尝试落盘，失败时才询问保存 / 放弃 / 取消。
- 恢复副本写在应用数据目录（`recovery/*.json`），不污染工作区，单份上限 8 MiB；正常保存或放弃修改后清理。恢复副本只进入编辑器，不会自动覆盖源文件。
- 外部修改检测基于文件 mtime，冲突时拒绝写入，绝不静默覆盖。自动保存遇到冲突会暂停，而不是反复重试。
- 图片粘贴/拖拽由 Rust 端校验真实图片头与 16 MiB 上限，只写入文档同级 `assets/`，文件名由服务端生成，不覆盖已有文件。
- 任何删除操作都需要确认，优先提供「移到回收站」而不是永久删除。

## 开发

### 前置要求

- Node.js 与 **Bun**
- **Rust** 工具链（stable）
- Tauri 2 的系统依赖：
  - Windows：WebView2（Windows 10/11 通常已内置）
  - macOS：Xcode Command Line Tools
  - Linux：WebKitGTK、libappindicator 等，参见 Tauri 官方文档

### 命令

```bash
bun install
bun run tauri dev     # 启动桌面开发模式
bun run build         # 构建前端
bun run tauri build   # 打包桌面安装包
```

> 首次 `bun run tauri dev` 会编译 Rust 依赖，耗时较长；之后增量编译会快很多。

> 仓库内的 `src-tauri/.cargo/config.toml` 把 crates.io 指向了 rsproxy 镜像，用于在无法直连 crates.io 的网络下构建。如果你的网络可以直接访问 crates.io，删除该文件即可恢复默认源。
